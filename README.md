# Triply

Веб-приложение для планирования путешествий: поездка, места, план по дням, карта, бюджет и совместная работа.
Командный проект по дисциплине «Создание программного обеспечения», РТУ МИРЭА, группа ЭФБО-03-24.

| Роль | Участник |
| --- | --- |
| Тимлид / аналитик | Зайцев А.А. |
| Frontend | Казакова А.В. |
| Backend | Севостьянова Е.К. |

## Ветки

| Ветка | Что в ней |
| --- | --- |
| `backend` | FastAPI, PostgreSQL, миграции, тесты, Docker, шпаргалка показа КТ-1 |
| `frontend` | React + TypeScript + Tailwind + Leaflet |

Подробности запуска — в README каждой ветки.
