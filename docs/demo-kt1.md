# КТ-1: показ бэкенда (шпаргалка)

Бэкенд показывается через Swagger — встроенную документацию, где каждый метод можно вызвать прямо из браузера.
Если что-то не запускается, показывайте скриншоты из папки `screenshots` по порядку — это тот же сценарий.

## Перед показом (за 5 минут)

1. `docker compose up --build`, затем `docker compose exec api python -m app.scripts.seed`.
2. Открыть http://localhost:8000/docs.
3. Нужен интернет — для живого поиска мест (Photon).

## Сценарий (≈5 минут)

| # | Что делаем в Swagger | Что говорим | Скриншот |
| --- | --- | --- | --- |
| 1 | Показать страницу целиком | «Все методы бэкенда к КТ-1: аккаунт, поездки и дни, места и активности, карта» | 01 |

| 4 | `GET /trips` | «Список моих поездок с ролью и числом дней» | 04 |
| 5 | `POST /trips` с датами 11–13 июня | «При создании поездки дни маршрута создаются сами — видно 3 дня» | 05 |
| 6 | `GET /trips/{trip_id}`, trip_id = 1 | «Поездка целиком: дни, активности по порядку, нераспределённые, места» | 06 |
| 7 | `PUT /trips/1/days/1/order` с `[3, 2, 1]` | «Так сохраняется порядок после перетаскивания на фронте» | 07 |

> Номера id в шагах 7–8 — для свежих демо-данных. Если выполняли запросы раньше, возьмите id из ответа шага 6.

## Если спросят

- **Почему 404, а не 403 для чужой поездки?** Чтобы нельзя было перебором узнать, какие поездки существуют.
- **Как хранятся пароли?** Только хеш argon2id, пароль в открытом виде нигде не сохраняется.
- **Что будет с активностями, если сократить даты поездки?** Они не удаляются, а переходят в «нераспределённые».
- **Почему деньги строкой (`"450.00"`)?** Чтобы JavaScript не терял копейки при округлении.
- **Откуда поиск мест?** Photon — бесплатный геокодер на данных OpenStreetMap; провайдера можно заменить без правок фронта.
- **Что дальше (КТ-2)?** Приглашения участников по ссылке, роли, расходы и «кто кому должен».
